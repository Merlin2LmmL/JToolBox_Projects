# JToolBox Projects

A collection of random Java projects I made during my time at **Dietrich-Bonhoeffer-Gymnasium**.

These projects were mostly created for school assignments, experiments, or the occasional “I have some free time, let's see what happens” session. They all use **BlueJ** and, for most of them, **Hans Witt's JToolBox**.

I figured putting them all in one place makes more sense than pretending each one deserves its own repository. If you're working with BlueJ, JToolBox, or simply learning Java, you might find something here useful as a reference or a bit of *inspiration*.

## Projects

| Project | Description |
|---|---|
| `01AutoschlangeMitContainer` | A rather random assignment involving a car object, extended with a surprisingly nice wheel animation. |
| `Game of Life` | Conway's Game of Life, thrown together during a bit of free time. Keep expectations low. |
| `Graph Implementierung Feld - Vorlage-KRC` | My first real encounter with graphs. Extended with major German train stations and implementations of DFS and Dijkstra. Essentially a tiny “Google Maps for trains”. |
| `Pacour_v2` | Team school project. I was mainly responsible for the tiled map system and contributed to player movement and map design. |
| `SchachbrettVorlage_2025` | An attempted chess implementation. I made it as far as the Queen before deciding that chess is, in fact, complicated. I later picked it up again when learning rust tho and created a pretty strong engine if you wanna check that out (; |
| `Snake` | Minimalistic Snake where the player controls how quickly the snake moves. I hadn't figured out proper timing yet. |
| `Super Mario` | An unfinished attempt at a block-based 2D game with chunks, a tiled system, and various block types. Very Bugged atm |

## About JToolBox

All of these projects use **Hans Witt's JToolBox**, which was used in our Java lessons.

It was honestly a major part of how I learned Java in the first place, so it deserves some credit here.

## Why is this one repository?

Because these projects are:

1. Mostly educational.
2. Built around a framework you're unlikely to encounter outside the context where we used it.
3. Usually nowhere near polished enough to justify their own repository.

So instead of giving every school assignment its own carefully crafted GitHub home, this repository is essentially the **JToolBox Museum of Things I Made While Learning Java™**.

If you happen to find something useful here, feel free to use it as a reference or inspiration.
